# TG Users DB

Статический сайт (GitHub Pages) для хранения и поиска известной информации о пользователях Telegram.

## Возможности

- Поиск по юзернейму (@ или без), user ID или части имени
- История юзернеймов и имён с периодами
- Био, телефон, ссылки, теги, заметки
- Форма генерации JSON для добавления данных (`admin.html`)

## Как добавить данные

1. Открой `admin.html` на сайте, заполни форму и скопируй сгенерированный JSON-блок.
2. Вставь блок в массив `users` в файле `data/users.json`.
3. Сделай commit/push — сайт обновится автоматически.

## Импорт контактов из Telegram

1. В Telegram Desktop открой **Настройки → Продвинутые → Экспорт данных Telegram** и выбери «Контакты».
2. Распакуй архив и запусти конвертер:

   ```bash
   python tools/convert_tg_export.py path/to/contacts.json --output data/users.json
   ```

3. Залей получившийся `data/users.json` в репозиторий.

Полезные флаги: `--merge-existing data/users.json` (добавить к уже имеющейся базе без дублей), `--no-phone` (не публиковать телефоны), `--no-bio`, `--limit N` (проверить на первых N), `--tag "тег"` (добавить свой тег).

Группы, каналы и удалённые аккаунты отбрасываются автоматически.

## Прямой импорт из своего Telegram

`tools/tg_pull.py` логинится в твой аккаунт через официальный API и вытягивает контакты —
включая то, чего нет в HTML-экспорте: **ID, юзернеймы, био, имена**.

1. Получи `api_id` и `api_hash`: https://my.telegram.org → **API development tools**.
2. Установи зависимость и запусти:

   ```bash
   pip install telethon
   python tools/tg_pull.py --api-id 12345678 --api-hash aaa...bbb
   ```

   При первом запуске спросит номер телефона и код из Telegram (и пароль, если включена 2FA).

Полезные флаги:
- `--include-chats` — брать ещё людей из личных диалогов (не только сохранённые контакты);
- `--no-phone` — не публиковать телефоны (по умолчанию телефоны включены);
- `--no-bio` — быстрее, без запроса био;
- `--limit 10` — проверить на первых 10;
- `--search @user nick` — режим поиска: сохранить людей по юзернеймам/ID;
- `--tag "друг"` — добавить свой тег.

Записи догружаются в существующую базу без дубликатов (по id и телефону).
Историю старых имён/юзернеймов API не отдаёт — она будет копиться только с момента запусков.
